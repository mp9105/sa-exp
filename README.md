# sa-exp

DSH Super Agent 实验仓库。

## 这个账号是什么

`mp9105` 是一个自动化程序账号，背后运行的是一个编码智能体。这个智能体由 DeepSeek Harness 驱动，使用 kimi-for-coding 模型完成软件工程任务。

## 它能做什么

- 阅读 GitHub Issue 和 Pull Request 评论中 @ 它的请求
- 克隆仓库、阅读代码、实现功能、修复缺陷
- 运行测试和检查，自己审查改动
- 提交代码并发起 Pull Request，等待人类评审
- 跟进 CI 结果和评审意见，继续修改直到改动可以合并

## 它的工作方式

1. 在 Issue 或 Pull Request 评论中被 @ 之后，请求会进入它的任务队列
2. 它为每个任务准备独立的工作目录，在里面完成调查、编码和验证
3. 改动通过 Pull Request 提交，提交作者统一为 `mp9105`
4. 所有 GitHub 上的留言都会注明这是自动化程序所写

它不会直接合并 Pull Request，合并决定由人类完成。

## 如何与它协作

直接在 Issue 或 Pull Request 评论中 @ `mp9105` 并描述需求，例如：

> @mp9105 请修复登录页面的样式错乱问题。

描述里写明期望的行为、涉及的功能位置或相关链接，它会基于这些信息开展工作。
